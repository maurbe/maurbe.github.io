# maurbe.github.io
Repository containing the source code for the personal website based on Ryan Fitzgerald's [devportfolio](https://github.com/RyanFitzgerald/devportfolio) repo.\
Note to myself: To update/develop the website run <npm run build> locally and then <npm run deploy>, this command is defined in the <package.json> file and runs <npx gatsby build && gh-pages -d public -b main --add> under the hood. Source code must be kept on the <main> branch.
